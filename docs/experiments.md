# 实验说明

| 任务 | 基线 | DIM-IAG-RS | 绝对提高 |

来源：研究稿《Deep Intensity Mapping with Risk-Aware Residual Suppression for Low-Light Image Enhancement in High-Level Vision》，表1和表5。相对基线的增幅分别约28.7%和26.7%，与绝对百分点差不同。

这些数值对应研究稿实验配置，原始检查点与完整日志未包含，且发布代码与最终运行配置未完成完全对齐。当前入口的medium preset不能据此视为上述结果的完整复现配置。其他下游任务不补列缺少对应记录的数值。

## 评价与限制

mAP50-95对0.50至0.95共10个IoU阈值计算并平均，检测框与实例掩码分别评价。PSNR、主观亮度与固定模型识别效果衡量的目标不同。整体结果不能单独归因于门控、小波或RS中的某一个模块；模块贡献需要控制其他因素的消融对照。

原始权重缺失时，随机初始化输出不用于增强效果评估。`validate_release.py`的严格加载检查只验证权重与结构兼容，不验证指标或生成质量。
