# 单门控 DIM IAG RS 低光增强项目档案

## 要解决的问题

低光图像增强的最终目标是帮助后续识别。单纯提高亮度或 PSNR，可能同时放大暗部噪声、造成过曝，或者改变固定下游模型熟悉的图像分布。因此这个项目把检测与分割表现作为直接评价依据。

本次面试与代码整理只采用单门控版本：DIM-WRR 基础增强 → IAG 预测空间门控 → RS 修正有效残差。已提供的源码含基础 DIM、Haar 小波残差分支和门控实现，源码沿用的 MIT 版权必须保留，不能把全部上游结构声明为个人首创。

## 用一条公式串起代码

`Y = clamp(X + G * S * (Y_base - X), 0, 1)`。

X 是归一化 RGB 输入，`Y_base-X` 是候选增强残差，G 是学习到的门控，S 是推理时根据风险构造的残差调节图。G 和 S 都是 `[B,1,H,W]`，乘 RGB 残差时按通道广播。S 在部分 preset 中允许轻微大于 1，因此应称为风险调节或抑制策略，不把它描述为数学上始终只减小残差。

DIM 基础网络先用卷积和 C3k2 下采样提取特征，用 A2C2f 处理深层表示，再逐级融合与上采样。`intensity_mapping(x)=2x-x²` 作用于中间特征；不能未经范围假设就说任意中间特征都被安全限制在 [0,1]。

DIM-WRR 将输入与 DIM 输出做 Haar 分解，拼接两组小波系数预测残差，再重建 RGB 修正。`base_alpha` 控制这部分修正进入基础图像的比例。IAG 使用输入、基础图像、反射率代理和光照/噪声/边缘等信息预测一个空间门控，避免各处采用相同增强量。

RS 位于 `scripts/enhance_single_gate.py`，不是全都封装在模型的 forward 里：

`S = clamp(1 - w_noise*N - w_over*O + w_under*U, s_min, s_max)`。

噪声代理 N 与过曝风险 O 降低残差，欠曝图 U 允许保留更多增强。N 是网络估计的风险代理，不是带有噪声真值保证的物理测量。RS 是该入口的推理策略，不额外使用下游标签，也不应说成训练期新增的监督损失。

## 源码阅读路线

`dim_iag_rs/dim.py::DIM.forward` → `dim_wrr.py::DIM_WRR.forward` → `dim_wrr_iag.py::make_base_enhancement/forward` → `scripts/enhance_single_gate.py::main` → `tools/eval`。

IAG 的输入总计 16 通道：X/Y_base/反射率代理各 3，光照、噪声、亮度、边缘、残差幅度、欠曝、过曝各 1。反射率代理是 `clamp(X/(I+eps),0,1)`，不要宣称严格恢复了真实反射率。

| 论文 DIM-IAG-RS 配置 | 0.502 | 0.384 |

## 失败与局限

强增强会放大噪声；过强抑制又可能保留欠曝。风险图可能把纹理当噪声，clamp 在饱和区也会丢失信息。下游收益依赖数据域、固定识别模型及评测协议，不能说任何图像都会改善。PSNR、视觉效果和下游 mAP 衡量不同目标，需要并列看。

## 30 秒介绍

我把未发表的低光研究整理为任务导向增强项目，重点是增强后能否改善检测和分割。流程以 DIM-WRR 得到基础增强，再通过光照感知门控和风险残差调节控制增强幅度。历史论文实验中，LOD 检测与 LIS 掩码 mAP50–95 分别从 0.390/0.303 提高到 0.502/0.384。现在以单门控版本讲解与整理源码。

## 2 分钟介绍

低光增强中，图像更亮不一定更容易识别，尤其是暗部噪声和高光过曝。我采用一条残差控制主线解释方法：基础网络给候选增强，门控决定每个区域采用多少残差，风险调节进一步抑制噪声与过曝。代码中 DIM 做特征映射和多尺度融合，小波分支补充残差，IAG 融合 16 通道信息输出单通道空间权重。RS 在推理脚本里显式计算，最后得到 X 加有效增强残差。评价时关注固定下游模型上的检测与分割，而不只看 PSNR。论文配置记录了任务指标改善，但缺少原检查点，当前整理版没有重新验证这些数值。我能解释方法、已有实验结论和实现版本的差异，不把工程整理说成新的实验提升。

## 5 分钟讲述顺序

依次讲任务目标与噪声/过曝矛盾、DIM-WRR 特征与小波路径、16 通道 IAG、推理阶段的 RS 公式、历史检测分割结果和版本限制。最后给一个“增强太强伤害结构”和一个“过度保守保留欠曝”的失败情形，说明下一步怎样设计消融；这些情形是分析，不伪装成新实验截图。
