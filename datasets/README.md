# Datasets

This repository does not include dataset files.

The experiments are conducted on four datasets:

- CODaN for image classification evaluation
- ACDC for semantic segmentation evaluation
- LOD for object detection evaluation
- LIS for instance segmentation evaluation

Please prepare the datasets according to their official protocols and configure local paths in the files under `configs/`.

Detailed dataset organization and evaluation settings are provided in:

docs/dataset_preparation.md
